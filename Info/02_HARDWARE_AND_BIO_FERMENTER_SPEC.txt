3. สูตรหมักปุ๋ยน้ำชีวภาพ 3 ถัง (ระดับทดลอง 1 ลิตรต่อถัง)

> หมายเหตุ: ใช้กระบวนการหมักแบบใช้อากาศ (Aerobic Fermentation) โดยเปิดปั๊มลมตั้งเวลา (เช่น ทำงาน 15 นาที พัก 45 นาที) เพื่อเร่งจุลินทรีย์และลดกลิ่นไม่พึงประสงค์ระหว่างตั้งแสดงในงานประกวด

| ถังหมัก | ธาตุหลัก | วัตถุดิบตั้งต้น (ต่อน้ำ 1 ลิตร) | สารเสริมจุลินทรีย์ | ระยะเวลาหมัก & เตรียมก่อนโชว์ |
| :--- | :---: | :--- | :--- | :--- |
| โหลที่ 1 (N-Bio) | ไนโตรเจน (N) | เศษพืชตระกูลถั่ว / กากถั่วเหลือง / ผักใบเขียวสดสับละเอียด (~200–300 กรัม) | กากน้ำตาล 50 ml + หัวเชื้อจุลินทรีย์ (EM/พด.2) 30 ml + น้ำสะอาดเติมจนครบ 1 L | หมัก 7–14 วัน ครบกำหนดกรองผ่านผ้าขาวบาง + ตะแกรง 100–150 µm ให้ใส ก่อนเทลงช่อง `N` ของเครื่องจ่ายปุ๋ย |
| โหลที่ 2 (P-Bio) | ฟอสฟอรัส (P) | ขั้นที่ 1 (7 วัน): กระดูกสัตว์คั่วแห้งบดหยาบ ~50 กรัม แช่ในน้ำส้มสายชูหมัก 500 ml (อัตรา 1:10) ทิ้งไว้ 7 วันและคนวันละครั้ง (ไม่ต้องรอสังเกตฟอง $\text{CO}_2$) แล้วกรองเอาน้ำใส (WCP)<br>ขั้นที่ 2 (7–14 วัน): นำน้ำ WCP ผสมรำละเอียด ~150 กรัม *(ห้ามใช้เปลือกไข่แทนแหล่ง P)* | กากน้ำตาล 50 ml + หัวเชื้อจุลินทรีย์ 30 ml + น้ำสะอาดเติมจนครบปริมาตรใช้งาน 1 L (ในโหล 2 L) | รวมระยะเตรียมทั้งหมด 14–21 วัน (เริ่มตั้งแต่ Day 0) กรอง 2 ชั้นให้ใสสะอาดมากก่อนเทลงช่อง `P` |
| โหลที่ 3 (K-Bio) | โพแทสเซียม (K) | หยวกกล้วย / เปลือกกล้วยสุกสับละเอียด (~250–300 กรัม) | กากน้ำตาล 50 ml + หัวเชื้อจุลินทรีย์ 30 ml + น้ำสะอาดเติมจนครบ 1 L | หมัก 7–14 วัน กรองกากใยกล้วยออกให้ใสมากก่อนเทลงช่อง `K` |

4. ขั้นตอนการสอบเทียบฮาร์ดแวร์ก่อนใช้งานจริง (Calibration Checklist)

ก่อนนำไปเขียนค่าคงที่ลงซอฟต์แวร์ ต้องตรวจเช็กและวัดค่าจริงต่อไปนี้ทุกครั้ง:

1. อัตราการไหลปั๊มจุ่ม 4 ตัวในเครื่องเดิม (`Back/`):
   - เครื่องเดิมสอบเทียบและตั้งค่าไว้ใน `app/config.py` แล้ว (`N=3.03, P=2.00, K=6.40, W=22.08 ml/s`) ห้ามดัดแปลงสายยางหรือรื้อปั๊มเดิม — หากต้องการทวนสอบให้วางเหยือกตวงใต้หัวจ่ายสีแดงแล้วสั่งทดสอบทีละช่อง 10 วินาที $\times$ 3 รอบ แล้วหาค่าเฉลี่ย $Q_{\text{pump},i} = V_{\text{avg}}/10$
   - ข้อปฏิบัติสำคัญ: เนื่องจากเป็นปั๊มจุ่มแช่อยู่ก้นช่อง `W, K, P, N` หลังสาธิตทุกครั้งให้เปิดบอลวาล์วด้านหน้าเครื่องถ่ายน้ำปุ๋ยออกและล้างด้วยน้ำสะอาดเพื่อไม่ให้ตะกอนอุดตันใบพัดปั๊ม
2. ทดสอบการรับส่งกล่องวัดดินไร้สาย (`Arduino Uno + LoRa RA-02`):
   - เปิด Power Bank ในกล่องวัดดิน แล้วตรวจสอบที่ `GET /api/soil/hw-status` หรือหน้าเว็บว่า `soil_receiver.packet_count` เพิ่มขึ้นและได้ค่า `pH, N, P, K` ตรงตามถาดดินจริง (หรือลองเสียบ USB Serial สำรอง)
3. สอบเทียบน้ำหนักขึ้นบินโดรน (Payload Margin Test):
   - ชั่งน้ำหนักชุดตลับพ่น + ปั๊ม 3V + แบต 1S + สวิตช์ + น้ำ 8–10 ml (เป้าใช้งานจริง `22–23 g`, เพดานสูงสุด `≤ 25 g`) $\rightarrow$ ทดลองสั่ง Hover สูง 50 ซม. นาน 60 วินาที สังเกตความร้อนมอเตอร์และการลอยตัวนิ่ง
4. สอบเทียบค่า TDS/EC น้ำหมักตั้งต้น (Salinity/Osmotic Guard):
   - วัดค่า TDS/EC ของน้ำหมัก N, P, K ที่กรองแล้ว หลังผสมเจือจางในถัง 1,000 ml แล้วเท่านั้น (ช่วงวัดหัววัด 0–1,000 ppm; ถ้าน้ำหมักตั้งต้นเข้มข้นเกิน 1,000 ppm ให้เจือจางน้ำหมักในถังตั้งต้นลงก่อนใช้งาน) เพื่อคุมความปลอดภัยไม่ให้ใบไหม้ แล้วล้างหัววัดด้วยน้ำสะอาดหลังวัดทุกครั้ง
5. ตรวจเช็คความปลอดภัยทางไฟฟ้า (Hardware Safety):
   - ต่อ Ground (GND) ร่วมกันระหว่างบอร์ด ESP32 กับโมดูลรีเลย์/เซนเซอร์ และต่อ Flyback Diode (`1N4007`) คร่อมขั้วปั๊มทุกตัว (หันแถบสีเงินเข้าขั้ว `+`) ป้องกันไฟกระชากย้อน
   - วางถาดรองพลาสติกกันน้ำใต้ถังหมัก ถังผสม และพื้นที่บินพ่นบนโต๊ะ แยกตำแหน่งปลั๊กไฟและบอร์ดให้อยู่สูงกว่าขอบถาดรองน้ำ

5. ข้อกำหนดเชิงลึกด้านไฟฟ้า เฟิร์มแวร์ และเครือข่าย (กัน AI เขียนโค้ดผิด)

ส่วนนี้สรุปข้อจำกัดทางฮาร์ดแวร์ที่ AI มักเดาผิดเวลาช่วยเพื่อนเขียนโค้ด Arduino/ESP32:

5.1 ข้อกำหนด Analog ADC ของ ESP32 (ห้ามใช้สูตร Arduino Uno!)
- ความละเอียดและแรงดันอ้างอิง: ADC ของ ESP32 เป็น 12-bit (`0 – 4095`) ที่แรงดัน 3.3V *(ไม่ใช่ 10-bit `0–1023` ที่ 5V แบบ Arduino Uno)*
- กฎ ADC1 vs ADC2: ขณะ ESP32 เปิด Wi-Fi ขา `ADC2` (`GPIO 0, 2, 4, 12, 13, 14, 15, 25, 26, 27`) ไม่สามารถอ่าน `analogRead()` ได้ ต้องต่อเซนเซอร์ Analog ที่ขา `ADC1` เท่านั้น:
- `ESP32 (แบบ B — ถังหมัก & TDS)`: ใช้ `GPIO 35` (`ADC1`) สำหรับหัววัด `TDS/EC (Analog)` และ `GPIO 4` สำหรับ `DS18B20` 3 ตัว (ส่วนการคุมปั๊ม 4 ตัวและหัววัดดิน RS485 ย้ายไปต่อตรงที่ Pi 5 GPIO `17, 27, 22, 23` และ Arduino USB/LoRa แล้ว)
  *(หมายเหตุ: ห้ามต่อเซนเซอร์ Analog เข้า Raspberry Pi 5 โดยตรงเพราะหัวต่อ 40-pin ของ Pi 5 ไม่มีขา ADC ในตัว ต้องอ่านผ่านขา ADC1 ของ ESP32 เท่านั้น)*
- ความปลอดภัยแรงดัน: ห้ามป้อนสัญญาณ Analog > `3.3V` เข้าขา GPIO ของ ESP32 (โมดูล TDS ทั่วไปเอาต์พุตสูงสุด `2.3V` จึงต่อเข้าตรงได้ แต่หากใช้บอร์ดที่จ่าย `0–5V` ต้องทำ Voltage Divider ก่อน)

5.2 สูตรอ่านค่า TDS/EC บน ESP32 3.3V (พร้อมชดเชยอุณหภูมิ)
ใช้สมการมาตรฐานนี้ในโค้ด ESP32 #2 (ดึงอุณหภูมิน้ำ $T$ เฉลี่ยหรือ $25.0^\circ\text{C}$ มาชดเชย):
1. แปลงค่า Analog เป็นแรงดัน (แนะนำให้ใช้ฟังก์ชัน `analogReadMilliVolts(pin)` ของ ESP32 Arduino Core ซึ่งชดเชยความไม่เป็นเชิงเส้นของ ADC ให้แล้ว):
   $$V_{\text{adc}}\text{ (V)} = \frac{\text{analogReadMilliVolts(pin)}}{1000.0}$$
2. ชดเชยอุณหภูมิเทียบที่ $25^\circ\text{C}$ (ใช้ค่าคงที่ $T_{\text{water}} = 25.0^\circ\text{C}$ เพราะมี DS18B20 เฉพาะถังหมัก 3 ถังและถังผสมมีน้ำเปล่า ~60%):
   $$V_{\text{comp}} = \frac{V_{\text{adc}}}{1.0 + 0.02 \times (T_{\text{water}} - 25.0)}$$
3. คำนวณค่า TDS (ppm):
   $$\text{TDS (ppm)} = \big(133.42 \times V_{\text{comp}}^3 - 255.86 \times V_{\text{comp}}^2 + 857.39 \times V_{\text{comp}}\big) \times 0.5 \times K_{\text{cal}}$$
   *(คูณ `0.5 * K_cal` กับพหุนามทั้งหมดในวงเล็บ โดย $K_{\text{cal}}$ คือค่าตัวคูณสอบเทียบเทียบกับน้ำยาสอบเทียบ EC/TDS มาตรฐาน และให้กวน/เขย่าถังผสมเบาๆ ก่อนจุ่มวัดทุกครั้ง)*

5.3 กฎ Relay Active-LOW และลำดับการเปิดปั๊มบน Raspberry Pi 5 (`Back/`)
- บอร์ด Relay 6 ช่องสีฟ้าในชั้นบนของเครื่องเดิมต่อใช้งาน 4 ช่องแบบ Active-LOW (`LOW` = เปิดปั๊ม, `HIGH` = ปิดปั๊ม) เข้ากับ Raspberry Pi 5 (`GPIO 17=N, 27=P, 22=K, 23=W`) ไว้เรียบร้อยแล้ว *(บอร์ด ESP32 ไม่ต้องต่อรีเลย์ปั๊ม)*
- โค้ด `app/hardware_bridge.py` ฝั่ง Pi 5 สั่งเปิดปั๊ม ทีละ 1 ตัว (Sequential: `N → P → K → W`) ด้วยตัวจับเวลา `time.perf_counter()` และมี Fail-safe ปิดทุกช่องเมื่อหยุดหรือปิดโปรแกรม (`atexit`) เพื่อป้องกันกระแสกระชากหรือปั๊มค้าง

5.4 กฎ DS18B20 แบบ 1-Wire 3 ตัวขนานบน `GPIO 4`
- เมื่อต่อ DS18B20 ทั้ง 3 ตัวรวมกันที่ `GPIO 4` (พร้อม R Pull-up `4.7 kΩ` ไป `3V3`) ไลบรารี `DallasTemperature` จะเรียง `index 0, 1, 2` ตามเลข 64-bit ROM Address ไม่ได้เรียงตามลำดับที่เสียบ
- วิธีล็อกช่องถังให้ถูก: ต้องทดสอบอ่าน Address ทีละหัว (หรือจับจุ่มน้ำอุ่นทีละตัว) แล้ว Hardcode `DeviceAddress tankN = {...};` ลงในโค้ด ESP32 #2
- ช่วงอุณหภูมิอ้างอิงการหมัก: จุลินทรีย์ EM/การหมักใช้อากาศทำงานได้ดีในช่วง 25 – 40°C หากเกิน 45°C มีความเสี่ยงต่อการตายของจุลินทรีย์

5.5 สถาปัตยกรรมเครือข่าย Dual-Wi-Fi (สำหรับ Raspberry Pi 5 + ESP32 + โดรน)
- วงที่ 1 (Hotspot / Router 2.4 GHz): Raspberry Pi 5 (Wi-Fi ในตัว) + ESP32 (1 บอร์ด) + โน้ตบุ๊ก/มือถือสำหรับเปิดดูหน้าเว็บ ต่อเข้าวงเดียวกัน (ต้องเป็น 2.4 GHz เท่านั้น เพราะ ESP32 ไม่รองรับ 5 GHz) โดยฝั่ง Flask บน Pi 5 รันแบบ `host='0.0.0.0'` พอร์ต `5000` (หากเปิด Firewall บน Linux ให้ `sudo ufw allow 5000`) และตั้ง IP ของ Pi 5 ให้คงที่
- วงที่ 2 (USB Wi-Fi Dongle บน Raspberry Pi 5): เสียบ USB Wi-Fi Adapter ที่ Pi 5 เพื่อต่อเข้า Wi-Fi ของโดรนโดยตรง โดยไม่ตั้ง Default Gateway บนวงนี้ (`wlan1`) เพื่อให้ Pi 5 ยังโหลดแผนที่ Leaflet และคุยกับ ESP32 บนวงที่ 1 (`wlan0`) ได้พร้อมกันโดยไม่หลุด
