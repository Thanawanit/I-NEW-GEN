งานของคนที่ 2: ฝั่ง IoT, เครื่องหมัก 3 ถัง, สถานีผสมปุ๋ย และหัววัดดิน

2.1 รายการอุปกรณ์ที่ต้องดูแล
- ชุดฮาร์ดแวร์เดิมที่มีแล้วใน `Back/` (`INEWGEN` — ไม่ต้องซื้อใหม่):
  - Raspberry Pi 5 (1 บอร์ด) + รีเลย์ 4 ช่อง Active-LOW (`GPIO 17, 27, 22, 23`) + ปั๊ม Peristaltic 4 ตัว ที่สอบเทียบแล้ว (`N=3.03`, `P=2.00`, `K=6.40`, `W=22.08 ml/s`) + ถังน้ำปุ๋ย 1 ลิตร (3 ใบ) และถังน้ำ 4 ลิตร (1 ใบ)
  - Arduino + บอร์ด MAX485 (`D3, D4, D5`) + หัวจิ้มดิน RS485 (`Back/sketch/sketch.ino`) + โมดูล LoRa RA-02 (ทางเลือก; บนโต๊ะใช้สาย USB เสียบ Pi 5)
- ส่วนที่เบิก/เตรียมเพิ่มสำหรับชุดถังหมัก & เช็กความเค็ม (ESP32 แบบ B):
  1. บอร์ด ESP32 (1 บอร์ด), สายจัมเปอร์, เบรดบอร์ด
  2. โหลหมักใส 2 ลิตร (3 ใบ — ใช้หมักแยกข้างนอก แล้วกรองใสก่อนเทใส่ถัง `1,000 ml` ของเครื่องเดิม; ห้ามดัดแปลงเครื่องผสมปุ๋ยเดิม)
  3. ปั๊มลมตู้ปลา + ตัวแยก 3 ทาง + วาล์วปรับลม 3 ตัว + หัวฟู่ 3 หัว + สายยางซิลิโคน
  4. เซนเซอร์วัดอุณหภูมิน้ำกันน้ำ 1-Wire (DS18B20 จำนวน 3 ตัว ติดถังหมัก N, P, K) + ตัวต้านทาน 4.7 kΩ (1 ตัว)
  5. ผ้าขาวบาง / ตะแกรงกรองละเอียด `≤ 100–150 µm` (ใช้กรองน้ำหมักให้ใสก่อนเทลงเครื่องผสมเดิม) + เซนเซอร์วัดความเข้มข้นน้ำ (TDS/EC Analog 3.3V) 1 ชุด

2.2 ผังการต่อสายแบบละเอียด (ทำตามนี้ได้เลย ไม่ต้องเดา)

> กฎเหล็ก (ห้ามพลาด):
> 1. ปั๊ม 4 ตัว + รีเลย์ ต่อตรงเข้า Raspberry Pi 5 ตามชุดเดิมใน `Back/`: `N=GPIO 17`, `P=GPIO 27`, `K=GPIO 22`, `Water=GPIO 23` (Active-LOW)
> 2. หัวจิ้มดิน RS485 ต่อเข้า Arduino (`MAX485 RO->D3, DI->D4, DE/RE->D5`) แล้วเสียบสาย USB เข้า Pi 5
> 3. ESP32 (แบบ B) อ่านเฉพาะ DS18B20 3 ตัว (`GPIO 4`) + TDS/EC (`GPIO 35`, ADC1) เท่านั้น

ก. ส่วนตรวจวัดดินบนโต๊ะ (Arduino RS485 — มีโค้ดพร้อมแล้วใน `Back/sketch/sketch.ino`)
- อัปโหลด `Back/sketch/sketch.ino` ลงบอร์ด Arduino แล้วเสียบสาย USB Serial เข้า Raspberry Pi 5 (ระบบเว็บใหม่รองรับข้อความ `pH:6.5,N:20,P:15,K:30` ที่ `POST /api/soil/update` อัตโนมัติ)

ข. ส่วนถังหมัก 3 ถัง + หัววัด TDS/EC (ESP32 1 บอร์ด — แบบ B)
1. ต่อ DS18B20 ทั้ง 3 ตัว (1-Wire ต่อขนานกัน):
   - รวมสายสีแดง (`VCC`) ทั้ง 3 เส้น -> ขา `3V3` ของ ESP32
   - รวมสายสีดำ (`GND`) ทั้ง 3 เส้น -> ขา `GND` ของ ESP32
   - รวมสายสีเหลือง/ขาว (`DATA`) ทั้ง 3 เส้น -> ขา `GPIO 4` *(DS18B20 เป็น Digital ใช้ GPIO 4 ได้)*
   - เอาตัวต้านทาน 4.7 kΩ ต่อคร่อมระหว่างขา `GPIO 4 (DATA)` กับขา `3V3` (ขาดตัวนี้จะอ่านค่าได้ `-127°C`)
2. ต่อเซนเซอร์ TDS/EC (Analog):
   - `VCC` -> `3V3`, `GND` -> `GND`, `AO` -> `GPIO 35` (ADC1)
   - *ข้อห้าม:* ห้ามแช่หัววัด TDS/EC ทิ้งไว้ในถังผสมตลอดเวลา เพราะกรดน้ำหมักจะกัดหัววัด ให้จุ่มวัดเฉพาะหลังผสมเสร็จ 5 วินาที แล้วยกขึ้นจุ่มล้างในแก้วน้ำสะอาด
3. การเดินสายท่อดูดน้ำหมักเข้าปั๊ม Peristaltic ชุดเดิม (`Back/`):
   - เจาะฝาถังหมัก 4 จุดเล็กๆ: 1) สายลม+หัวฟู่ลงก้นถัง 2) ท่อดูดน้ำหมักติดตะแกรงกรอง `≤ 100–150 µm` ที่ปลายท่อ 3) สายโพรบ DS18B20 4) รูระบายอากาศเล็กๆ (ห้ามปิดฝาสนิท 100%)
   - วางชุดถังลงในถาดพลาสติก ส่วนบอร์ด ESP32, Arduino, Pi 5 และปลั๊กไฟให้วางสูงกว่าขอบถาด

2.3 วิธีเชื่อมต่อและทดสอบกับเว็บของคนที่ 1 (บน Raspberry Pi 5)
1. ต่อ Raspberry Pi 5 และ ESP32 (แบบ B) เข้า Wi-Fi 2.4 GHz วงเดียวกัน โดยฝั่ง Flask บน Pi 5 รันแบบ `host='0.0.0.0'` พอร์ต `5000` (หากเปิด Firewall บน Linux ให้ `sudo ufw allow 5000`)
2. ให้คนที่ 1 พิมพ์ `hostname -I` บน Pi 5 เพื่อดูเลข IP แล้วนำมาใส่ในโค้ด ESP32:
   - ESP32 ยิง `POST http://<IPของPi5>:5000/api/fermenter/telemetry` ส่ง JSON:
     `{"temp_n": 31.2, "temp_p": 30.8, "temp_k": 31.5, "temp_mixer": null, "mixer_tds_ppm": null, "simulated": false}` *(ส่ง `mixer_tds_ppm: null` ระหว่างเช็กอุณหภูมิปกติ และส่งค่าตัวเลข 30-sample median เฉพาะตอนจุ่มวัดหลังผสมเสร็จแล้วเท่านั้น)*
   - การสั่งปั๊ม 4 ตัว: กดสั่งจากหน้าเว็บได้เลย (`POST /api/mixer/dispense-live`) ตัว Flask บน Pi 5 จะเปิดปั๊มที่ขา `GPIO 17, 27, 22, 23` ทีละตัวโดยตรง (ESP32 ไม่ต้อง poll `/api/mixer/command` แล้ว)
3. Arduino RS485: ยิงค่าผ่าน `Back/pc_usb_bridge.py` หรือสคริปต์ส่งเข้า `POST http://<IPของPi5>:5000/api/soil/update` ด้วย JSON `{"plot_id": 1, "raw": "pH:6.5,N:20,P:15,K:30", "source": "arduino_usb"}`

2.4 ข้อมูลที่คนที่ 2 ต้องส่งให้คนที่ 1
- ค่าอัตราไหลปั๊ม 4 ตัว (มีแล้วจาก `Back/`): `N=3.03, P=2.00, K=6.40, W=22.08 ml/s` (ใส่ลง `config.py` แล้ว หากเปลี่ยนสายยางหรือหัวกรองหนาขึ้นให้วัดทวนซ้ำ 10 วินาที × 3 รอบ)
- [ ] ค่า 64-bit ROM Address ของ DS18B20 ทั้ง 3 ถัง (`N, P, K`)
- [ ] ค่า TDS/EC ตั้งต้นของน้ำหมัก N, P, K ที่กรองแล้ว และค่า TDS ของน้ำเปล่าที่ใช้เจือจาง (`water_tds_ppm`)

งานของคนที่ 3: ฝั่งโดรนสำรวจ + ชุดตลับพ่นปุ๋ย Modular (≤ 25 กรัม)

3.1 เช็คลิสต์และ "คำถามเจาะจงสำหรับถามร้านขายโดรน"
ตอนไปดูของหรือทักแชทร้าน ห้ามถามแค่ว่า "สั่งบินอัตโนมัติได้ไหม" เพราะคนขายมักตอบรวมๆ ว่าได้ (ซึ่งอาจหมายถึงแอปมือถือ) ให้ถามเจาะจงตามนี้:
- [ ] *"ตัวนี้รองรับการเขียนโค้ด Python ผ่าน Wi-Fi (UDP/TCP SDK) เช่น ไลบรารี `djitellopy` หรือโปรโตคอล MAVLink/ESP-Drone จากคอมพิวเตอร์โดยตรงไหม?"* (ถ้าใช้ได้แค่รีโมทหรือแอปมือถือ ห้ามซื้อ)
- [ ] *"มีกล้องจับพื้นด้านล่าง (Optical Flow Sensor) สำหรับลอยตัวนิ่งในห้องโดยไม่มี GPS ไหม?"*
- [ ] *"มีกล้องหน้าความละเอียดอย่างน้อย 720p ส่งภาพสด/ภาพนิ่งเข้าคอมฯ ผ่าน Wi-Fi ได้ไหม?"*
- [ ] *"ตัวโดรนหนักประมาณเท่าไหร่ และรับน้ำหนักเพิ่มอีก 25–30 กรัม ได้ไหม?"*
- [ ] ซื้อแบตสำรองเพิ่มให้มีรวมอย่างน้อย 2 ก้อน (รอบสำรวจ 1 ก้อน + รอบพ่น 1 ก้อน)
- [ ] ซื้อ USB Wi-Fi Adapter (2.4 GHz) สำหรับเสียบ Raspberry Pi 5 จำนวน 1 ตัว (เพื่อให้ Pi 5 ต่อ Wi-Fi โดรนได้พร้อมๆ กับต่อ Hotspot คุยกับ ESP32)

3.2 ขั้นตอนประกอบชุดตลับพ่น Modular (รอบบินที่ 2)
1. อุปกรณ์บนตลับพ่น:
   - ขวด/หลอดพลาสติกบาง 15 ml (แบบมีฝาเกลียวปิดสนิท เติมใช้งานจริง 8–10 ml)
   - ปั๊มน้ำไมโคร 3V น้ำหนักเบา + ท่อซิลิโคนสั้นๆ (ยาวแค่ 3–5 ซม. เพื่อลดน้ำหนัก) + หัวสเปรย์รู 0.2–0.4 mm *(ห้ามใช้แผ่น Piezo รู 5 µm เพราะจะตัน)*
   - แบตเตอรี่ LiPo 1S 3.7V จิ๋ว (100–200 mAh) + สวิตช์เลื่อนจิ๋ว (≤ 1 กรัม นับรวมในงบขวด/สายไฟ 5 g)
2. วิธีเจาะฝาขวด (สำคัญมาก):
   - เจาะรูที่ฝา 2 รู: รูที่ 1 สอดสายดูดลงก้นขวด (ยาแนวกันรั่ว), รูที่ 2 เจาะรูเข็มเล็กๆ ไว้ระบายอากาศ *(ถ้าไม่เจาะรูอากาศ ปั๊มดูดน้ำไม่ออกเพราะเกิดสุญญากาศ)*
3. การชั่งน้ำหนักและหาจุดศูนย์ถ่วง (ห้ามเกิน 25 กรัมเด็ดขาด):
   - เติมน้ำเปล่าทดสอบ 8–10 ml -> ชั่งรวมทั้งหมด (น้ำ 8–10g + ปั๊ม 3V ≤ 6g + แบตจิ๋ว ≤ 4g + ขวด/หัวพ่น/ท่อ/สวิตช์/ตีนตุ๊กแก ≤ 5g) เป้าใช้งานจริง `22–23 g` (เพดานสูงสุด `≤ 25 g` เพื่อให้มี margin `≥ 2 g`)
   - วางทาบใต้ท้องโดรนแล้วลองใช้นิ้ว 2 นิ้วประคองใต้โดรนเพื่อเช็กว่าไม่เอียงไปด้านหน้าหรือด้านหลัง
4. ตำแหน่งห้ามบัง:
   - พลิกดูใต้ท้องโดรน จะเห็นรูเลนส์กล้อง Optical Flow และรูเซนเซอร์วัดความสูง ห้ามติดตีนตุ๊กแกหรือขวดน้ำบังรูนี้เด็ดขาด (ไม่งั้นโดรนจะไถลชนกำแพง)

3.3 ขั้นตอนทดสอบบินก่อนรวมระบบกับคนที่ 1
1. เสียบ USB Wi-Fi Adapter เข้า Raspberry Pi 5 -> กดเชื่อม Wi-Fi ของโดรน (ส่วน Wi-Fi ตัวในของ Pi 5 ยังเชื่อม Hotspot 2.4 GHz อยู่)
2. ทดสอบรอบที่ 1 (ตัวเปล่า): รันสคริปต์ Python ทดสอบ Take off -> เดินหน้า 50 cm -> หมุน 90° -> ถ่ายภาพนิ่ง 1 ภาพ -> Land
3. ทดสอบรอบที่ 2 (ติดตลับพ่น + น้ำ 8–10 ml): ชั่งน้ำหนักรวมทั้งชุด ≤ 25 กรัม (ต้องลอง Hover ด้วยน้ำหนัก 25 g ดูก่อนซื้อ/ยืม) และวัดอัตราการพ่นของปั๊ม 3V เพื่อเช็กว่าน้ำไม่หมดก่อนบินจบเส้นทาง (แนะนำใช้สวิตช์ไร้สายหรือตั้งเวลาเปิดพ่นหลังขึ้นบิน)

3.4 ข้อมูลที่คนที่ 3 ต้องส่งให้คนที่ 1
- [ ] ชื่อไลบรารี Python และตัวอย่างโค้ดสั่งบิน + ดึงภาพของโดรนรุ่นที่ซื้อมา
- [ ] ระยะบินขั้นต่ำต่อ 1 คำสั่ง (เช่น 20 cm) และกรอบพื้นที่บินปลอดภัยบนถาดแปลง (ตั้งต้น `40 × 60 cm` บนถาด `60 × 80 cm`)
- [ ] ปริมาตรน้ำสูงสุดที่ใส่แล้วบินนิ่งที่สุด (เช่น `8–10 ml`, น้ำหนักรวม `≤ 25 g`)

งานของคนที่ 4: ฝั่งหมักปุ๋ยชีวภาพ, ดินจริง, ฐานข้อมูลพืช และเล่มรายงาน

4.1 ขั้นตอนหมักปุ๋ยชีวภาพ 3 ถัง (เริ่มตั้งแต่วันที่ 0 — ล่วงหน้า 3 สัปดาห์)
ไม่ต้องรอคนที่ 2 เจาะฝาถัง — ให้ซื้อโหลพลาสติกใสความจุ 2 ลิตร มาเริ่มหมักตั้งแต่วันนี้ทันที โดยใช้ปั๊มลมตู้ปลาแยกเติมอากาศและแง้มฝาโหลไว้ก่อน แล้วค่อยนำฝาให้คนที่ 2 เจาะรูติดเซนเซอร์ใน Day 3:

1. ถังที่ 1 — N-Bio (แหล่งไนโตรเจน):
   - สับเศษพืชตระกูลถั่ว / กากถั่วเหลือง / ผักใบเขียวสดให้ละเอียด ~200–300 กรัม ใส่ถัง
   - เติมกากน้ำตาล 50 ml + หัวเชื้อจุลินทรีย์ (EM หรือ พด.2) 30 ml + น้ำสะอาด (พักค้างคืนไล่คลอรีนแล้ว) เติมจนครบ 1 ลิตร (ในโหล 2 ลิตร)
- ถังที่ 2 — P-Bio (แหล่งฟอสฟอรัส — ทำ 2 ขั้น ใช้เวลารวม 14–21 วัน):
  - *ขั้นเตรียมกระดูก (WCP — แช่ 7 วัน):* นำกระดูกสัตว์สะอาดไป คั่วหรือเผาให้แห้งกรอบ แล้วทุบ/บดหยาบ ~50 กรัม -> แช่ในน้ำส้มสายชูหมัก 500 ml (อัตรา 1:10) ทิ้งไว้ 7 วันและคนวันละครั้ง *(ไม่ต้องรอสังเกตฟอง CO_2)* แล้วกรองเอาน้ำใส 500 ml (ห้ามใช้เปลือกไข่แทน เพราะเปลือกไข่จะได้แคลเซียม WCA ไม่ใช่ P)
  - นำน้ำสกัดกระดูกที่ได้ 500 ml + รำละเอียด ~150 กรัม + กากน้ำตาล 50 ml + EM 30 ml + น้ำสะอาดเติมจนครบ 1 ลิตร (ในโหล 2 ลิตร)
- ถังที่ 3 — K-Bio (แหล่งโพแทสเซียม):
  - สับหยวกกล้วยหรือเปลือกกล้วยสุกให้ละเอียด ~250–300 กรัม ใส่ถัง
  - เติมกากน้ำตาล 50 ml + EM 30 ml + น้ำสะอาดเติมจนครบ 1 ลิตร (ในโหล 2 ลิตร)
- การดูแลและเตรียมก่อนวันงาน:
  - เปิดปั๊มลมเติมอากาศ เปิด 15 นาที พัก 45 นาที (Aerobic) ช่วยให้จุลินทรีย์ย่อยเร็วและลดกลิ่นเหม็น จดบันทึกอุณหภูมิ/วันที่ทุก 2 วัน
  - ครบกำหนดให้กรองผ่าน ผ้าขาวบาง แล้วกรองซ้ำผ่าน ตะแกรง/ถุงกรองละเอียด ≤ 100–150 ไมครอน และหุ้มตาข่ายกรองรอบตัวปั๊มจุ่มก่อนวางก้นถัง

4.2 ขั้นตอนเก็บดินจริงและตรวจค่าดิน (ไม่มั่วตัวเลข)
1. วิธีขุดเก็บดินจากแปลงจริง (ทำ Composite Sample ตามมาตรฐานกรมพัฒนาที่ดิน):
   - เลือกแปลงปลูกจริงในพื้นที่ 1 แปลง เก็บ 3 จุด (บนเนิน, กลางแปลง, ตีนเนิน) ลึก 0–15 เซนติเมตร จุดละ ~300 กรัม *(หมายเหตุทางวิชาการ: การเก็บดินลึก 0–15 ซม. เป็นมาตรฐานการเก็บดินวิเคราะห์เคมี โดยระบบอนุมานว่าเป็นความเข้มข้นเฉลี่ยตลอดเขตรากพืช)*
   - ผึ่งลมในร่มให้หมาด (ห้ามตากแดดจัด) บดก้อนดินให้ร่วน แล้ว คลุกดินทั้ง 3 จุดรวมกันเป็นตัวอย่างรวม 1 ชุด เพื่อใช้ตรวจค่าตัวแทนของแปลง (หรือใช้ค่าจากจุดที่ต่ำที่สุด)
2. วิธีตรวจค่าดินด้วยชุดตรวจดิน (LDD Soil Test Kit หรือชุดตรวจภาคสนาม):
   - ติดต่อขอชุด LDD Soil Test Kit จากสถานีพัฒนาที่ดินจังหวัด/อำเภอ (หรือซื้อชุดตรวจดินภาคสนาม)
   - ตักดินตัวอย่างผสมน้ำยาสกัดตามคู่มือในกล่อง -> เขย่าแล้วตั้งทิ้งไว้ให้ตกตะกอนใส -> ดูดน้ำใสมาหยดน้ำยาทดสอบเทียบสีกับแผ่นชาร์ต
   - จดผลค่า `pH` และระดับ `N, P, K` (`ต่ำมาก / ต่ำ / ปานกลาง / สูง / สูงมาก` หรือ `ต่ำ / ปานกลาง / สูง`) ของทั้ง 3 จุด พร้อมถ่ายรูปเทียบสีเก็บไว้ใส่รายงาน
3. เปิดเทียบเกณฑ์กรมวิชาการเกษตร (2565):
   - หาตัวเลขคำแนะนำปุ๋ย (กก. N, P_2O_5, K_2O ต่อไร่) ของ ข้าวโพดเลี้ยงสัตว์, ถั่วลิสงพันธุ์ลายเสือ, กาแฟอราบิก้า แยกตามพันธุ์และ 3 ระยะเติบโต (ต้นกล้า / เจริญเติบโต / ออกดอก-ติดผล) เพื่อนำมาอัปเดตในตารางไฟล์ `03_SOFTWARE_FORMULAS_AND_CROP_DB`

4.3 การจัดเตรียมถาดแปลงจำลองบนโต๊ะพรีเซนต์
1. ถาดแปลงสำหรับโดรนบินถ่ายรูปและพ่น: ใช้ถาดพลาสติกขอบเตี้ย (ขนาดประมาณ 60 × 80 ซม.) วางต้นกล้าจำลองสีเขียวสดบนพื้นสีน้ำตาล/ดำที่ตัดกันชัด (ช่วยให้กล้องโดรนแยกสีเขียว ExG ได้แม่นยำ) และกันน้ำกระเด็นโดนอุปกรณ์อื่น
2. ถาดดิน 3 จุด: ใส่ดินจริง 3 จุดที่เก็บมาลงในกล่อง/ถาดเล็ก 3 ใบ ติดป้าย `จุด A (บนเนิน)`, `จุด B (กลางแปลง)`, `จุด C (ตีนเนิน)` วางคู่กันเพื่อให้คนที่ 2 จิ้มหัววัดโชว์ค่าสดหน้างานได้ทันที
