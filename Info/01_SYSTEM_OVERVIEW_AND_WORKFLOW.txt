1. แนวคิดหลักของโครงงานใหม่

ระบบบูรณาการการทำงานตั้งแต่ การสำรวจแปลงบนแผนที่ดิจิทัล $\rightarrow$ การบินสำรวจภาพถ่ายทางอากาศ $\rightarrow$ การตรวจวัดธาตุอาหารในดิน $\rightarrow$ การหมักและผสมปุ๋ยน้ำชีวภาพสั่งตัดเฉพาะจุด $\rightarrow$ การบินโปรยปุ๋ยสาธิตด้วยโดรนขนาดเล็ก เพื่อแก้ปัญหาต้นทุนปุ๋ยเคมีและการจัดการธาตุอาหารที่ไม่ตรงตามความต้องการจริงของพืช


1. ปุ๋ยน้ำชีวภาพสั่งตัดเฉพาะจุด (Site-Specific Bio-Liquid Fertilizer): เปลี่ยนจากการผสมแม่ปุ๋ยเคมี เป็นการใช้ เครื่องหมักปุ๋ยน้ำชีวภาพ 3 ถังแยกธาตุ N, P, K จากวัสดุท้องถิ่น แล้วผสมตามอัตราส่วนที่ดินขาดจริง
2. Human-in-the-Loop Map Calibration: ผู้ใช้ลากเส้นขอบเขตบนแผนที่ภาพถ่ายดาวเทียมฟรี (ไม่ต้องใช้บัตรเครดิต/API Key) เพื่อคำนวณพื้นที่อัตโนมัติ พร้อมเปิดให้ ยืนยันหรือแก้ไขตัวเลขพื้นที่จริง ก่อนส่งต่อให้ระบบคำนวณและย่อสเกลบิน
3. Controlled Dilution & 15-Point Averaging: ใช้ค่าเฉลี่ยจากกล่องวัดดินไร้สายสูงสุด 15 จุด (ป้องกันค่าดินเพี้ยนจากจุดเดียว) ร่วมกับการเจือจางในถังผสมมาตรฐาน `1,000 ml` (น้ำหมักชีวภาพรวมสูงสุด `400 ml` + น้ำเปล่า `600 ml` และตัวกันปั๊มเปิดสั้นเกินไป `min_pump_runtime_s`) เพื่อคุมความเข้มข้นให้ปลอดภัยต่อใบพืช *(ตัดหัววัด TDS/EC และ ESP32 ออกแล้วใน `v1.8`)*
4. Modular Micro-Drone: ใช้โดรนขนาดเล็ก 1 ลำสลับภารกิจ 2 รอบ (รอบที่ 1 บินถ่ายภาพประเมินพื้นที่สีเขียว, รอบที่ 2 ติดตลับพ่นละอองฝอยขนาดจิ๋วพร้อมหัวฉีดรู 0.2–0.4 mm บินโปรยปุ๋ย) เพื่อให้บินในร่มบนโต๊ะเดโมได้อย่างปลอดภัยภายใต้งบจำกัด

3. Workflow การทำงาน 8 ขั้นตอน (Demo Flow)

| ขั้นตอน | กิจกรรมหลัก | กลไกการทำงานและการเชื่อมข้อมูล |
| :---: | :--- | :--- |
| 1 | เปิดเว็บแอปพลิเคชัน (บนโน้ตบุ๊ก) | เปิดเว็บใหม่ (`app/app.py`) บนโน้ตบุ๊ก แล้วใส่ IP ของ Raspberry Pi 5 เดิม (`http://<IP>:10000`) ในหน้าตั้งค่าเพื่อเชื่อมเครื่องเดิมโดยไม่ต้องแก้ไขโค้ดใน Pi 5 |
| 2 | กำหนดขอบเขตแปลง & ยืนยันพื้นที่ | ลากเส้น Polygon บนแผนที่ดาวเทียม (Leaflet) $\rightarrow$ ระบบคำนวณพื้นที่ ($\text{m}^2$) $\rightarrow$ ผู้ใช้กด ยืนยัน หรือ แก้ไขตัวเลขพื้นที่จริง และตั้งค่าสเกลย่อส่วนสำหรับพื้นที่บินบนโต๊ะ |
| 3 | กรอกข้อมูลพืชเป้าหมาย | เลือก ชนิดพืช (ข้าว / กระเทียม / ถั่วลิสง (ถั่วลายเสือ) / ข้าวโพดเลี้ยงสัตว์ — มีเกณฑ์ DOA/ARDA ในฐานข้อมูลแล้ว 120 โปรไฟล์ ครอบคลุม 15 สายพันธุ์), พันธุ์, ระยะการเจริญเติบโต และเนื้อดินแม่ฮ่องสอน 5 ชนิด |
| 4 | โดรนรอบที่ 1: บินสำรวจถ่ายภาพ | เว็บแปลงเส้นทางขอบเขตเป็นคำสั่งบินอัตโนมัติย่อสเกล (ระยะ $\text{cm}$ และมุมเลี้ยว) ส่งให้โดรนบินถ่ายภาพแปลงจำลอง $\rightarrow$ ส่งภาพกลับเข้าเว็บเพื่อคำนวณค่าพื้นที่สีเขียว (ExG) |
| 5–6 | ตรวจค่าดิน 1–15 จุดเข้าเว็บทันที | จิ้มกล่องวัดดินไร้สาย 5 เข็ม (`Arduino Uno + MAX485 + Power Bank`) ลงถาดดินจริงจากแปลง (รองรับ 1–15 จุด พร้อมเสียงแนะนำในเว็บ) ค่าส่งผ่าน LoRa RA-02 (433 MHz) เข้า Raspberry Pi 5 อัตโนมัติ |
| 7 | คำนวณสูตร & จ่ายปุ๋ยลงเหยือกผสม | คำนวณ $\Delta N, \Delta P, \Delta K$ จากค่าเฉลี่ยจุดตรวจดิน (สมดุลมวล + Random Forest) $\rightarrow$ Pi 5 สั่งปั๊มจุ่ม 4 ตัว (GPIO 17, 27, 22, 23) จ่ายน้ำหมักกรองใส (หรือน้ำสีจำลองตอนถ่ายคลิป) ลง เหยือกผสมภายนอก 1,000 ml |
| 8 | โดรนรอบที่ 2: เติมปุ๋ยและบินโปรย | ถอดกล้อง/ปรับโหมดเป็นชุดพ่น Modular $\rightarrow$ ตักน้ำปุ๋ยที่ผสมเสร็จใส่ตลับสเปรย์ 8–10 ml (น้ำหนักใช้งานจริง `22–23 g` ใต้เพดานสูงสุด `≤ 25 g`) $\rightarrow$ โดรนบินตามเส้นทางเดิมเหนือถาดแปลงจำลองพร้อมพ่นละอองฝอยสาธิต |

5. คำถามที่พบบ่อย (FAQ) สำหรับเตรียมตอบกรรมการ

1. ทำไมต้องให้ผู้ใช้แก้ไขค่าพื้นที่ที่คำนวณจากแผนที่ได้?
   - เพราะภาพถ่ายดาวเทียมอาจมีขอบเขตที่ถูกเงาต้นไม้บังหรือความลาดชันบนดอยสูง ทำให้เส้นที่ลากคลาดเคลื่อนจากพื้นที่เพาะปลูกจริง การเปิดให้เกษตรกร/ผู้ใช้งานตรวจสอบและยืนยันหรือแก้ตัวเลขได้ ช่วยป้องกันการคำนวณปุ๋ยผิดพลาดทั้งแปลง
2. ทำไมไม่ติดหัววัด NPK ลงบนตัวโดรนแล้วบินไปปักเอง?
   - หัววัด NPK ชนิดแท่งเหล็กต้องใช้แรงกดแทงลงดินลึก 5–10 ซม. และหนักเกินกำลังยกของโดรนสาธิตขนาดเล็ก หากบินลงปักบนดินแข็งจะทำให้โดรนเสียการทรงตัวหรือใบพัดเสียหาย จึงออกแบบให้โดรนเน้นสำรวจและพ่น ส่วนการวัดดินใช้ชุดตรวจภาคพื้น/ถาดตัวอย่างเพื่อให้ได้ค่าที่เสถียรและปลอดภัยในสเกลเดโม (ในระดับอุตสาหกรรมจริงจะแยกเป็นโดรนสำรวจกับหุ่นยนต์ภาคพื้นหรือสถานีตรวจดินประจำแปลง)
3. น้ำหมักชีวภาพมีตะกอน จะอุดตันปั๊มจุ่มหรือหัวพ่นหรือไม่?
   - ออกแบบให้หมักแบบเติมอากาศ (Aerobic) ในโหลภายนอก แล้ว กรองผ่านผ้าขาวบาง + ตะแกรงละเอียด (≤ 100–150 µm) ให้ใส ก่อนเทลงช่องเก็บ `N, P, K` ของเครื่องจ่ายปุ๋ยเดิม (ซึ่งใช้ปั๊มจุ่ม 4 ตัวก้นช่อง และมีบอลวาล์วระบายน้ำด้านหน้าสำหรับล้างทำความสะอาดหลังใช้งานทุกครั้ง) คู่กับ หัวสเปรย์รู 0.2–0.4 mm (200–400 µm) บนโดรนแทนแผ่น Piezo (รู 5 µm) จึงไม่ตันง่าย
4. จะมั่นใจได้อย่างไรว่าปุ๋ยที่ผสมไม่เข้มข้นเกินไปจนต้นไม้ตาย?
   - ระบบควบคุมอัตราส่วนเจือจางในถังผสม `1,000 ml` โดยจำกัดปริมาตรน้ำหมักชีวภาพรวมไม่เกิน `400 ml` และเติมน้ำเปล่าเจือจางอีก `600 ml` (อัตราส่วนเจือจาง 40:60 พร้อมตัดปั๊มที่ต่ำกว่า `min_pump_runtime_s`) ทำให้ความเข้มข้นอยู่ในช่วงปลอดภัยต่อการพ่นทางใบ *(ในรุ่น `v1.8` ตัดเซนเซอร์ TDS/EC ออกเพื่อลดความซับซ้อนของฮาร์ดแวร์)*

1. โปรโตคอลสื่อสารกลาง: ใช้ HTTP/1.1 REST JSON บน Flask พอร์ต `5000` (`Frontend ↔ Flask` และ `Pi 5 :10000 ↔ โน้ตบุ๊ก`, ไม่ใช้ MQTT, WebSocket, Firebase) ส่วน `Flask ↔ โดรน` ใช้ SDK ของโดรน (UDP/TCP) และกล่องวัดดินใช้ LoRa RA-02 (433 MHz) / USB Serial
2. อุปกรณ์ที่ตัดออกใน `v1.8`: ไม่ใช้บอร์ด ESP32, หัววัดอุณหภูมิ DS18B20, หัววัด TDS/EC และชุด LDD Test Kit
3. ระบบแผนที่: ใช้ Leaflet.js + Esri World Imagery (ฟรี ไม่ต้องใช้ Google Maps API Key และไม่ผูกบัตรเครดิต)
4. การควบคุมปั๊มจ่ายปุ๋ย: Pi 5 คุมรีเลย์ปั๊มจุ่ม 4 ช่องตรงผ่าน `GPIO 17 (N), 27 (P), 22 (K), 23 (Water)`
5. หัวพ่นโดรน: ใช้ Micro Spray Nozzle รู 0.2–0.4 mm + ปั๊มไมโคร 3V เติมน้ำปุ๋ย 8–10 ml โดย น้ำหนักรวมทั้งชุดพ่น (รวมน้ำ, ปั๊ม, แบต, ตลับ, หัวพ่น, ท่อ) ≤ 25 กรัม (ห้ามใช้แผ่น Piezo 5 µm เพราะน้ำหมักจะอุดตันทันที)
6. ส่วนหมักปุ๋ย (เสร็จสิ้นแล้ว): น้ำหมัก N, P, K ดำเนินการเสร็จสิ้นแล้ว ไม่ต้องทำเพิ่ม (ใช้กรองใส `≤ 100–150 µm` เติมเข้าช่องเครื่องจ่ายปุ๋ย หรือใช้น้ำสีจำลองตอนถ่ายคลิป)
7. ขอบเขตงานโดรน: ใช้โดรนขนาดเล็กบินในร่มบนถาดแปลง `60 × 80 cm` (กรอบบินปลอดภัย `40 × 60 cm` หักขอบด้านละ 10 cm) ด้วย Optical Flow โดยไม่ติดหัววัดดินบนตัวโดรน (หัววัดดินจิ้มบนถาดตัวอย่างบนโต๊ะแทน)
8. การแยกแหล่งข้อมูล (Data Provenance): ระบบต้องแยกระหว่าง `LIVE` (อุปกรณ์จริง) กับ `SIMULATED` (ข้อมูลจำลองทดสอบ) แยกฐานข้อมูลและสถานะ UI กัน 100% — ข้อมูลจำลองทุกชนิดต้องส่ง `"mode": "sim"` หรือ `"simulated": true` ห้ามปนกับข้อมูลจริง
