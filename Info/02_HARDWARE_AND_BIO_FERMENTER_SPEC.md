## 3. สูตรหมักปุ๋ยน้ำชีวภาพ 3 ถัง (ระดับทดลอง 1 ลิตรต่อถัง)

> หมายเหตุ: ใช้กระบวนการหมักแบบใช้อากาศ (**Aerobic Fermentation**) โดยเปิดปั๊มลมตั้งเวลา (เช่น ทำงาน 15 นาที พัก 45 นาที) เพื่อเร่งจุลินทรีย์และลดกลิ่นไม่พึงประสงค์ระหว่างตั้งแสดงในงานประกวด

| ถังหมัก | ธาตุหลัก | วัตถุดิบตั้งต้น (ต่อน้ำ 1 ลิตร) | สารเสริมจุลินทรีย์ | ระยะเวลาหมัก & เตรียมก่อนโชว์ |
| :--- | :---: | :--- | :--- | :--- |
| **ถังที่ 1 (N-Bio)** | **ไนโตรเจน (N)** | เศษพืชตระกูลถั่ว / กากถั่วเหลือง / ผักใบเขียวสดสับละเอียด (~200–300 กรัม) | กากน้ำตาล 50 ml + หัวเชื้อจุลินทรีย์ (EM/พด.2) 30 ml + น้ำสะอาดเติมจนครบ 1 L | หมัก 7–14 วัน กรองกากหยาบออก 1 รอบก่อนตั้งโชว์ และติดตะแกรงกรองปลายท่อดูด |
| **ถังที่ 2 (P-Bio)** | **ฟอสฟอรัส (P)** | **ขั้นที่ 1 (5–7 วัน):** กระดูกสัตว์คั่วแห้งบดหยาบ ~50 กรัม แช่ในน้ำส้มสายชูหมัก **500 ml** (อัตรา 1:10) จนฟอง $\text{CO}_2$ หยุดฟู่แล้วกรองเอาน้ำใส (WCP)<br>**ขั้นที่ 2 (7–14 วัน):** นำน้ำ WCP ผสมรำละเอียด ~150 กรัม *(ห้ามใช้เปลือกไข่แทนแหล่ง P)* | กากน้ำตาล 50 ml + หัวเชื้อจุลินทรีย์ 30 ml + น้ำสะอาดเติมจนครบปริมาตรใช้งาน 1 L (ในโหล 2 L) | รวมระยะเตรียมทั้งหมด **12–21 วัน** (ต้องเริ่มทำตั้งแต่ Day 0 ก่อนวันงาน ~3 สัปดาห์) กรอง 2 ชั้นก่อนเข้าปั๊ม |
| **ถังที่ 3 (K-Bio)** | **โพแทสเซียม (K)** | หยวกกล้วย / เปลือกกล้วยสุกสับละเอียด (~250–300 กรัม) | กากน้ำตาล 50 ml + หัวเชื้อจุลินทรีย์ 30 ml + น้ำสะอาดเติมจนครบ 1 L | หมัก 7–14 วัน กรองกากใยกล้วยออกให้ใสก่อนต่อเข้าปั๊ม |

## 4. ขั้นตอนการสอบเทียบฮาร์ดแวร์ก่อนใช้งานจริง (Calibration Checklist)

ก่อนนำไปเขียนค่าคงที่ลงซอฟต์แวร์ ต้องวัดค่าจริงต่อไปนี้ทุกครั้ง:

1. **สอบเทียบอัตราการไหลปั๊ม ($Q_{\text{pump}}$) และไล่น้ำเต็มท่อ (Pre-priming) ทั้ง 4 ตัว:**
   - ก่อนใช้งานจริงต้องกดไล่น้ำให้เต็มสายยางจนถึงตำแหน่ง Check Valve ทุกเส้น เพื่อไม่ให้มีช่องอากาศทำให้ปริมาตรคลาดเคลื่อน
   - สั่งเปิดปั๊มทีละตัวเป็นเวลา $t = 10$ วินาที $\rightarrow$ ตวงปริมาตรน้ำที่ได้ ($V$ หน่วย $\text{ml}$) ทำซ้ำ 3 รอบแล้วหาค่าเฉลี่ย:
     $$Q_{\text{pump}, i} = \frac{V_{\text{avg}}}{10}\quad (\text{ml/s})$$
   - ควรเลือกปั๊มที่มีอัตราไหลไม่เร็วเกินไป (หรือหรี่วาล์ว/กำหนดปริมาตร Batch ที่ 200 ml) เพื่อให้เวลาเปิดปั๊มแต่ละตัวไม่ต่ำกว่า **1.5 วินาที** ลดความคลาดเคลื่อนช่วงปั๊มออกตัว (Pump Dead-time)
2. **สอบเทียบน้ำหนักขึ้นบินโดรน (Payload Margin Test):**
   - ชั่งน้ำหนักชุดตลับพ่น + ปั๊ม 3V + แบต 1S + น้ำ 8–10 ml (รวม ≤ 25 g) $\rightarrow$ ทดลองสั่ง Hover สูง 50 ซม. นาน 60 วินาที สังเกตความร้อนมอเตอร์และการลอยตัวนิ่ง
3. **สอบเทียบค่า TDS/EC น้ำหมักตั้งต้น (Salinity/Osmotic Guard):**
   - วัดค่า TDS/EC ของน้ำหมัก N, P, K ที่กรองแล้ว **หลังผสมเจือจางในถัง 200 ml แล้วเท่านั้น** (ช่วงวัดหัววัด 0–1,000 ppm) เพื่อคุมความปลอดภัยไม่ให้ใบไหม้ แล้วล้างหัววัดด้วยน้ำสะอาดหลังวัดทุกครั้ง *(หมายเหตุ: หากใช้ค่าอุณหภูมิเฉลี่ยจากถังหมักแทนอุณหภูมิจริงในถังผสมที่มีน้ำเปล่า ~60% ค่า TDS อาจคลาดเคลื่อนได้ราว 3–5%)*
4. **ตรวจเช็คความปลอดภัยทางไฟฟ้า (Hardware Safety):**
   - ต่อ Ground (GND) ร่วมกันระหว่างบอร์ด ESP32 กับโมดูลรีเลย์/เซนเซอร์
   - วางถาดรองพลาสติกกันน้ำใต้ถังหมัก ถังผสม และพื้นที่บินพ่นบนโต๊ะ แยกตำแหน่งปลั๊กไฟและบอร์ดให้อยู่สูงกว่าขอบถาดรองน้ำ

## 5. ข้อกำหนดเชิงลึกด้านไฟฟ้า เฟิร์มแวร์ และเครือข่าย (กัน AI เขียนโค้ดผิด)

ส่วนนี้สรุปข้อจำกัดทางฮาร์ดแวร์ที่ AI มักเดาผิดเวลาช่วยเพื่อนเขียนโค้ด Arduino/ESP32:

### 5.1 ข้อกำหนด Analog ADC ของ ESP32 (ห้ามใช้สูตร Arduino Uno!)
- **ความละเอียดและแรงดันอ้างอิง:** ADC ของ ESP32 เป็น **12-bit (`0 – 4095`)** ที่แรงดัน **3.3V** *(ไม่ใช่ 10-bit `0–1023` ที่ 5V แบบ Arduino Uno)*
- **กฎ ADC1 vs ADC2:** ขณะ ESP32 เปิด Wi-Fi ขา `ADC2` (`GPIO 0, 2, 4, 12, 13, 14, 15, 25, 26, 27`) **ไม่สามารถอ่าน `analogRead()` ได้** ต้องต่อเซนเซอร์ Analog ที่ขา **`ADC1` เท่านั้น**:
  - `ESP32 #1` (Soil Moisture/EC Analog): **`GPIO 34`**
  - `ESP32 #2` (TDS/EC Analog): **`GPIO 35`**
- **ความปลอดภัยแรงดัน:** ห้ามป้อนสัญญาณ Analog > `3.3V` เข้าขา GPIO ของ ESP32 (โมดูล TDS ทั่วไปเอาต์พุตสูงสุด `2.3V` จึงต่อเข้าตรงได้ แต่หากใช้บอร์ดที่จ่าย `0–5V` ต้องทำ Voltage Divider ก่อน)

### 5.2 สูตรอ่านค่า TDS/EC บน ESP32 3.3V (พร้อมชดเชยอุณหภูมิ)
ใช้สมการมาตรฐานนี้ในโค้ด ESP32 #2 (ดึงอุณหภูมิน้ำ $T$ เฉลี่ยหรือ $25.0^\circ\text{C}$ มาชดเชย):
1. แปลงค่า Analog เป็นแรงดัน (แนะนำให้ใช้ฟังก์ชัน `analogReadMilliVolts(pin)` ของ ESP32 Arduino Core ซึ่งชดเชยความไม่เป็นเชิงเส้นของ ADC ให้แล้ว):
   $$V_{\text{adc}}\text{ (V)} = \frac{\text{analogReadMilliVolts(pin)}}{1000.0}$$
2. ชดเชยอุณหภูมิเทียบที่ $25^\circ\text{C}$ (ใช้ค่าคงที่ $T_{\text{water}} = 25.0^\circ\text{C}$ เพราะมี DS18B20 เฉพาะถังหมัก 3 ถังและถังผสมมีน้ำเปล่า ~60%):
   $$V_{\text{comp}} = \frac{V_{\text{adc}}}{1.0 + 0.02 \times (T_{\text{water}} - 25.0)}$$
3. คำนวณค่า TDS (ppm):
   $$\text{TDS (ppm)} = \big(133.42 \times V_{\text{comp}}^3 - 255.86 \times V_{\text{comp}}^2 + 857.39 \times V_{\text{comp}}\big) \times 0.5 \times K_{\text{cal}}$$
   *(คูณ `0.5 * K_cal` กับพหุนามทั้งหมดในวงเล็บ โดย $K_{\text{cal}}$ คือค่าตัวคูณสอบเทียบเทียบกับน้ำยาสอบเทียบ EC/TDS มาตรฐาน และให้กวน/เขย่าถังผสมเบาๆ ก่อนจุ่มวัดทุกครั้ง)*

### 5.3 กฎ Relay Active-LOW, แรงดัน 3.3V และลำดับการเปิดปั๊ม
- บอร์ด Relay 4 ช่องทั่วไปทำงานแบบ **Active-LOW** (`LOW` = เปิดปั๊ม, `HIGH` = ปิดปั๊ม)
- **การต่อไฟเลี้ยงวงจรรีเลย์กับ ESP32 3.3V:** หากใช้บอร์ดรีเลย์ 5V ที่มีจัมเปอร์ `JD-VCC` ให้ **ถอดจัมเปอร์ออก** แล้วต่อ `VCC -> 3V3` (ฝั่งสัญญาณลอจิก) และต่อ `JD-VCC -> 5V` (ฝั่งคอยล์รีเลย์) เพื่อป้องกันไฟ 5V ย้อนทำให้รีเลย์ค้างไม่ยอมตัดเมื่อ ESP32 ส่ง `HIGH (3.3V)` (หากใช้รุ่นรองรับ 3.3V โดยตรงให้ต่อ `VCC -> 3V3`)
- **ห้ามเปิดปั๊มตอนบอร์ดบูต:** ใน `setup()` ต้องสั่ง `digitalWrite(pin, HIGH);` **ก่อน** `pinMode(pin, OUTPUT);` ทุกขา (`GPIO 25, 26, 27, 33` — ใช้เป็น Digital Output ได้ปกติ และหลีกเลี่ยงขา `GPIO 14` เพราะอาจมีพัลส์กระตุกตอนบูต)
- **เปิดปั๊มทีละ 1 ตัว (Sequential):** เพื่อป้องกันกระแสกระชาก (Inrush Current) จนไฟตกและบอร์ดรีเซ็ต ให้เปิดปั๊ม N $\rightarrow$ ปิด $\rightarrow$ เปิดปั๊ม P $\rightarrow$ ปิด $\rightarrow$ เปิดปั๊ม K $\rightarrow$ ปิด $\rightarrow$ เปิดปั๊มน้ำเปล่า $\rightarrow$ ปิด

### 5.4 กฎ DS18B20 แบบ 1-Wire 3 ตัวขนานบน `GPIO 4`
- เมื่อต่อ DS18B20 ทั้ง 3 ตัวรวมกันที่ `GPIO 4` (พร้อม R Pull-up `4.7 kΩ` ไป `3V3`) ไลบรารี `DallasTemperature` จะเรียง `index 0, 1, 2` ตามเลข **64-bit ROM Address** ไม่ได้เรียงตามลำดับที่เสียบ
- **วิธีล็อกช่องถังให้ถูก:** ต้องทดสอบอ่าน Address ทีละหัว (หรือจับจุ่มน้ำอุ่นทีละตัว) แล้ว Hardcode `DeviceAddress tankN = {...};` ลงในโค้ด ESP32 #2
- **ช่วงอุณหภูมิอ้างอิงการหมัก:** จุลินทรีย์ EM/การหมักใช้อากาศทำงานได้ดีในช่วง **25 – 40°C** หากเกิน **45°C** มีความเสี่ยงต่อการตายของจุลินทรีย์

### 5.5 สถาปัตยกรรมเครือข่าย Dual-Wi-Fi (สำหรับโน้ตบุ๊ก + ESP32 + โดรน)
- **วงที่ 1 (Hotspot / Router 2.4 GHz):** โน้ตบุ๊ก (Wi-Fi ในตัว) + ESP32 #1 + ESP32 #2 ต่อเข้าวงเดียวกัน (ต้องเป็น **2.4 GHz เท่านั้น** เพราะ ESP32 ไม่รองรับ 5 GHz) โดยฝั่ง Flask ต้องรันแบบ `host='0.0.0.0'` พอร์ต `5000` และ **เปิด Windows Firewall อนุญาตพอร์ต `5000`** พร้อมตั้ง IP โน้ตบุ๊กให้คงที่เพื่อไม่ให้ ESP32 หลุดการเชื่อมต่อ
- **วงที่ 2 (USB Wi-Fi Dongle):** เสียบ USB Wi-Fi Adapter ที่โน้ตบุ๊กเพื่อต่อเข้า Wi-Fi ของโดรนโดยตรง โดย**ไม่ตั้ง Default Gateway** บนวงนี้ เพื่อให้ระบบยังโหลดแผนที่ Leaflet และคุยกับ ESP32 บนวงที่ 1 ได้พร้อมกันโดยไม่หลุด
