ภาพรวมหน้าที่ทีม 4 คน
--------------------------------------------------------------------------------
1. คนที่ 1 (Software) : เว็บ Flask + แผนที่ Leaflet + สูตรคำนวณ + วิเคราะห์ภาพ + API กลาง
2. คนที่ 2 (IoT & เครื่องหมัก/ผสม) : วงจร ESP32 + ถังหมัก 3 ถัง + ปั๊ม 4 ตัว + หัววัดดิน/น้ำ
3. คนที่ 3 (Drone & ชุดพ่น) : จัดหาโดรน + ทำตลับพ่น <= 25 กรัม + ทดสอบบินผ่าน Python
4. คนที่ 4 (เกษตร & เล่มรายงาน) : หมักปุ๋ย 3 ถัง + เก็บดินจริง + ตรวจดิน + เกณฑ์พืช + เอกสารประกวด

งานของคนที่ 2 : ฝั่ง IoT, เครื่องหมัก 3 ถัง, สถานีผสมปุ๋ย และหัววัดดิน
================================================================================

[1] อุปกรณ์ที่ต้องดูแล
- บอร์ด Wi-Fi (ESP32) จำนวน 2 บอร์ด, สายจัมเปอร์, เบรดบอร์ด
- เช็กราคา/ซื้อตามสเปค 
  1) โหลหมักใสฝาเกลียว 1-1.5 ลิตร (3 ใบ) + ถังผสมกลางใส 0.5-1 ลิตร (1 ใบ) + ถาดพลาสติกรองน้ำ (1 ใบ)
  2) ปั๊มลมตู้ปลา + ตัวแยก 3 ทาง + วาล์วปรับลม 3 ตัว + หัวฟู่ 3 หัว + สายยางซิลิโคน
  3) เซนเซอร์วัดอุณหภูมิน้ำกันน้ำ 1-Wire (DS18B20) 3 ตัว + ตัวต้านทาน 4.7 kOhm (1 ตัว)
  4) ไส้กรอง/ตะแกรงตาข่ายละเอียด <= 100-150 ไมครอน (3 ชุด) + วาล์วกันไหลย้อน Check Valve (3-4 ตัว)
  5) ปั๊มน้ำ DC ขนาดเล็ก 4 ตัว (N, P, K, น้ำเปล่า) + บอร์ดรีเลย์ 4 ช่อง Logic 3.3V + Power Supply แยก (>= 3A-5A)
  6) เซนเซอร์วัดความเข้มข้นน้ำ (TDS/EC Analog 3.3V) 1 ชุด
  7) เซนเซอร์วัดความชื้น/EC ดิน (Analog 3.3V) 1 ชุด (ถ้างบเหลือค่อยเพิ่ม RS485 NPK+pH + MAX485)

[2] ผังการต่อสายแบบละเอียด (ทำตามนี้ได้เลย ไม่ต้องเดา)
*** กฎเหล็กของ ESP32 (ห้ามพลาด) ***
เมื่อ ESP32 เปิดใช้งาน Wi-Fi ขา Analog กลุ่ม ADC2 (GPIO 0, 2, 4, 12, 13, 14, 15, 25, 26, 27)
จะอ่านค่า Analog ไม่ได้! ดังนั้นเซนเซอร์ Analog ทุกตัว (TDS/EC และ Soil Probe)
ต้องต่อเข้าขา ADC1 เท่านั้น คือ GPIO 32, 33, 34, 35, 36 (VP), 39 (VN)

ก. การต่อวงจร ESP32 #1 (ชุดตรวจดินบนโต๊ะ)
- Soil Moisture / EC Probe (Analog 3.3V):
  * VCC -> ขา 3V3 ของ ESP32 #1
  * GND -> ขา GND ของ ESP32 #1
  * AO (Analog Out) -> ขา GPIO 34 (กลุ่ม ADC1)
- (กรณีได้ RS485 NPK+pH + MAX485: ต่อเข้า UART2 คือ TX=GPIO 17, RX=GPIO 16)

ข. การต่อวงจร ESP32 #2 (ถังหมัก 3 ถัง + สถานีผสม 4 ปั๊ม)
1. ต่อ DS18B20 ทั้ง 3 ตัว (1-Wire ต่อขนานกัน):
   * รวมสายสีแดง (VCC) ทั้ง 3 เส้น -> ขา 3V3 ของ ESP32 #2
   * รวมสายสีดำ (GND) ทั้ง 3 เส้น -> ขา GND ของ ESP32 #2
   * รวมสายสีเหลือง/ขาว (DATA) ทั้ง 3 เส้น -> ขา GPIO 4 (เป็น Digital ใช้ขา 4 ได้)
   * เอาตัวต้านทาน 4.7 kOhm ต่อคร่อมระหว่างขา GPIO 4 กับขา 3V3 (ถ้าไม่ใส่จะอ่านได้ -127 C)
2. ต่อเซนเซอร์ TDS/EC (Analog):
   * VCC -> 3V3, GND -> GND, AO -> ขา GPIO 35 (ADC1)
   * ข้อห้าม: ห้ามแช่หัววัด TDS/EC ทิ้งไว้ในถังผสมตลอดเวลา ให้จุ่มวัดเฉพาะหลังผสมเสร็จ 5 วินาที
     แล้วยกขึ้นจุ่มล้างในแก้วน้ำสะอาด
3. ต่อ Relay 4 ช่อง + ปั๊ม 4 ตัว (แยกไฟเลี้ยงกันบอร์ดพัง):
   * ฝั่งสัญญาณ (ESP32 -> Relay):
     - VCC รีเลย์ -> VIN (5V) ของ ESP32 #2
     - GND รีเลย์ -> GND ของ ESP32 #2
     - IN1, IN2, IN3, IN4 -> GPIO 25, 26, 27, 14 (ปั๊ม N, P, K, น้ำเปล่า)
   * ฝั่งกำลัง (Power Supply -> Relay -> ปั๊ม):
     - สายบวก (+) จาก Power Supply แยก -> แยกเข้าขา COM ของรีเลย์ทั้ง 4 ช่อง
     - ขา NO (Normally Open) ของแต่ละช่อง -> สายบวก (+) ของปั๊มตัวที่ 1-4
     - สายลบ (-) ของปั๊มทั้ง 4 ตัว -> สายลบ (-) ของ Power Supply แยก
     - สำคัญ: ต่อสาย GND (-) ของ Power Supply แยก เข้ากับ GND ของ ESP32 #2 ด้วย
4. การเดินสายยางถังหมักและถังผสม:
   * เจาะฝาถังหมัก 4 จุดเล็กๆ: ท่อลม+หัวฟู่ลงก้นถัง, ท่อดูดติดไส้กรอง <= 100-150 ไมครอน,
     สายโพรบ DS18B20, และ "รูระบายอากาศเล็กๆ" (ห้ามปิดฝาสนิท 100% เดี๋ยวก๊าซดันโหลบวม)
   * บนท่อส่งน้ำจากปั๊มเข้าถังผสมกลาง ให้ใส่ Check Valve โดยหันหัวลูกศรชี้ไปทางถังผสมกลาง
   * วางชุดถังทั้งหมดบนถาดพลาสติก ส่วนบอร์ด ESP32 และปลั๊กไฟวางให้สูงกว่าขอบถาด

[3] วิธีเชื่อมต่อและทดสอบกับเว็บของคนที่ 1
1. ต่อโน้ตบุ๊กของคนที่ 1 และ ESP32 ทั้ง 2 ตัวเข้า Wi-Fi วงเดียวกัน (แนะนำใช้ Hotspot มือถือเครื่องสำรอง)
2. ให้คนที่ 1 พิมพ์ ipconfig ในเครื่องเพื่อดู IPv4 Address ของโน้ตบุ๊ก (เช่น 192.168.137.1) แล้วใส่ในโค้ด ESP32:
   - ESP32 #1 ส่งค่าดินไปที่ POST http://<IPโน้ตบุ๊ก>:5000/api/soil/update
     JSON: {"plot_id": 1, "moisture_pct": 42.5, "ec_us_cm": 310}
   - ESP32 #2 ส่งค่าถังหมักไปที่ POST http://<IPโน้ตบุ๊ก>:5000/api/fermenter/telemetry
     JSON: {"temp_n": 31.2, "temp_p": 30.8, "temp_k": 31.5, "mixer_tds_ppm": 740}
   - ESP32 #2 ดึงคำสั่งเปิดปั๊มจาก GET http://<IPโน้ตบุ๊ก>:5000/api/mixer/command
     แล้วส่งผลเสร็จกลับไปที่ POST /api/mixer/status

[4] ข้อมูลที่คนที่ 2 ต้องวัดจริงและส่งให้คนที่ 1
1. วิธีสอบเทียบปั๊มทั้ง 4 ตัว:
   - จุ่มท่อดูดลงแก้วน้ำสะอาด -> เปิดปั๊มสั้นๆ ให้น้ำวิ่งเต็มสายยางจนถึงปลายท่อ (Pre-priming)
   - ย้ายปลายท่อมาใส่แก้วตวงเปล่า -> เปิดปั๊ม 10 วินาทีเป๊ะ -> อ่านปริมาตรน้ำ (ml)
   - ทำซ้ำ 3 รอบ หาค่าเฉลี่ย แล้วหารด้วย 10 จะได้ค่า ml/วินาที
2. ส่งค่าต่อไปนี้ให้คนที่ 1:
   ( ) Q_pump_N, Q_pump_P, Q_pump_K, Q_pump_water (ml/s)
   ( ) หมายเลขขา GPIO จริงที่ใช้ และชนิด Active Low/High ของบอร์ดรีเลย์
   ( ) ค่า TDS/EC ตั้งต้นของน้ำหมัก N, P, K ที่กรองแล้ว

[2] ขั้นตอนทำชุดตลับพ่น Modular (รอบบินที่ 2)
1. อุปกรณ์บนตลับพ่น:
   - ขวด/หลอดพลาสติกบาง 15-20 ml (ฝาเกลียวปิดสนิท)
   - ปั๊มน้ำไมโคร 3-5V น้ำหนักเบา + ท่อซิลิโคนสั้น 3-5 ซม. + หัวสเปรย์รู 0.2-0.4 mm
     (ห้ามใช้แผ่น Piezo รู 5 ไมครอน เพราะน้ำหมักชีวภาพจะอุดตันรูทันที)
   - แบต LiPo 1S 3.7V จิ๋ว (100-200 mAh) + สวิตช์เลื่อนจิ๋ว
2. วิธีเจาะฝาขวด (สำคัญมาก):
   - เจาะรูที่ฝา 2 รู: รูที่ 1 สอดสายดูดลงก้นขวด, รูที่ 2 เจาะรูเข็มเล็กๆ ไว้ระบายอากาศ
     (ถ้าไม่เจาะรูอากาศ ปั๊มจะดูดน้ำไม่ออกเพราะเกิดสุญญากาศ)
3. การชั่งน้ำหนักและหาจุดศูนย์ถ่วง (ห้ามเกิน 25 กรัมเด็ดขาด):
   - เติมน้ำเปล่าทดสอบ 10-13 ml -> ชั่งรวมทั้งชุดพ่น+แบตจิ๋ว+ตีนตุ๊กแก ต้อง <= 25 กรัม
   - วางทาบใต้ท้องโดรนแล้วใช้นิ้ว 2 นิ้วประคองดูว่าไม่เอียงหน้าหรือเอียงหลัง
4. ตำแหน่งห้ามบัง:
   - หงายท้องโดรนดูรูเลนส์กล้อง Optical Flow และเซนเซอร์วัดความสูง
     ห้ามติดตีนตุ๊กแกหรือขวดน้ำบังรูนี้เด็ดขาด (ไม่งั้นโดรนไถลชน)

[3] ขั้นตอนทดสอบบินก่อนรวมระบบกับคนที่ 1
1. เสียบ USB Wi-Fi Adapter เข้าโน้ตบุ๊กแล้วต่อ Wi-Fi โดรน (Wi-Fi ตัวในโน้ตบุ๊กยังต่อ Hotspot อยู่)
2. รอบที่ 1 (ตัวเปล่า): รันสคริปต์ Python สั่ง Take off -> เดินหน้า 50 cm -> หมุน 90 องศา -> ถ่ายรูป -> Land
3. รอบที่ 2 (ติดตลับพ่น + น้ำ 10 ml): เปิดสวิตช์ปั๊มพ่นก่อนปล่อยบิน -> สั่ง Hover สูง 50 cm นาน 60 วินาที

งานของคนที่ 4 : ฝั่งหมักปุ๋ยชีวภาพ, ดินจริง, ฐานข้อมูลพืช และเล่มรายงาน

[1] ขั้นตอนหมักปุ๋ยชีวภาพ 3 ถัง 
รอคนที่ 2 เจาะฝาถังและต่อสายลมเสร็จ แล้วทำตามสูตรต่อน้ำสะอาด 1 ลิตร ต่อถังดังนี้:
1. ถังที่ 1 (N-Bio ไนโตรเจน):
   - สับเศษพืชตระกูลถั่ว / กากถั่วเหลือง / ผักใบเขียวสด ~200-300 กรัม ใส่ถัง
   - เติมกากน้ำตาล 50 ml + หัวเชื้อจุลินทรีย์ (EM/พด.2) 30 ml + น้ำสะอาดพักค้างคืนจนครบ 1 ลิตร
2. ถังที่ 2 (P-Bio ฟอสฟอรัส — ทำ 2 ขั้นเพื่อไม่ให้เน่าและได้ P จริง):
   - ขั้นเตรียมกระดูก (WCP): นำกระดูกสัตว์สะอาดไป "คั่วหรือเผาให้แห้งกรอบ" (ไล่ไขมัน กันเหม็นเน่า)
     ทุบ/บดหยาบ ~50 กรัม -> แช่ในน้ำส้มสายชูหมักท่วมตัวกระดูก ทิ้งไว้จนฟองก๊าซ CO2 หยุดฟู่ (~5-7 วัน)
     แล้วกรองเอาน้ำใส (ห้ามใช้เปลือกไข่แทน เพราะเปลือกไข่จะได้แคลเซียม WCA ไม่ใช่ฟอสฟอรัส)
   - นำน้ำสกัดกระดูกที่ได้ + รำละเอียด ~150 กรัม + กากน้ำตาล 50 ml + EM 30 ml + น้ำครบ 1 ลิตร
3. ถังที่ 3 (K-Bio โพแทสเซียม):
   - สับหยวกกล้วยหรือเปลือกกล้วยสุก ~250-300 กรัม + กากน้ำตาล 50 ml + EM 30 ml + น้ำครบ 1 ลิตร
4. การดูแลและเตรียมก่อนวันงาน:
   - เปิดปั๊มลมเติมอากาศเป็นช่วงๆ (เช่น วันละ 2-3 รอบ) เพื่อเร่งย่อยและลดกลิ่นเหม็น
   - จดบันทึกวันเริ่มหมัก, อุณหภูมิ, สี, กลิ่น ทุก 2 วันไว้ใส่เล่มรายงาน
   - ครบ 7-14 วัน กรองผ่านผ้าขาวบาง แล้วกรองซ้ำผ่านตะแกรง/ถุงกรอง <= 100-150 ไมครอนก่อนต่อปั๊ม

[2] ขั้นตอนเก็บดินจริงและตรวจค่าดิน
1. วิธีขุดเก็บดินจากแปลงจริง:
   - เลือกแปลงปลูกจริง 1 แปลง แบ่งเก็บ 3 จุด (จุดบนเนิน, กลางแปลง, ตีนเนิน) ถ่ายรูปจุดเก็บไว้ด้วย
   - กวาดใบไม้ออก -> ขุดลึก 0-15 ซม. ตักจุดละ ~300-500 กรัม ใส่ถุงแยกเขียนป้ายชื่อจุด
   - ผึ่งลมในร่มให้หมาด (ไม่ตากแดดจัด) แล้วบดก้อนดินให้ร่วน
2. วิธีตรวจค่าดิน (LDD Soil Test Kit หรือชุดตรวจภาคสนาม):
   - ติดต่อขอชุด LDD Soil Test Kit ที่สถานีพัฒนาที่ดินจังหวัด/อำเภอ (หรือซื้อชุดตรวจภาคสนาม)
   - ตักดินผสมน้ำยาสกัดตามคู่มือ -> เขย่าตั้งให้ตกตะกอนใส -> ดูดน้ำใสหยดน้ำยาเทียบสีกับชาร์ต
   - จดผล pH และระดับ N, P, K (ต่ำ/ปานกลาง/สูง) ของทั้ง 3 จุด พร้อมถ่ายรูปเทียบสีเก็บไว้
3. เปิดเทียบคู่มือคำแนะนำการใช้ปุ๋ยสั่งตัดฯ (กรมวิชาการเกษตร, 2565):
   - รวบรวมเกณฑ์ กก. N, P2O5, K2O ต่อไร่ ของข้าวโพดเลี้ยงสัตว์, ถั่วลายเสือ, กาแฟอราบิก้า
     แยกตามพันธุ์และ 3 ระยะเติบโต (ต้นกล้า / เจริญเติบโต / ออกดอก-ติดผล)

[3] การจัดเตรียมถาดแปลงจำลองบนโต๊ะพรีเซนต์
1. ถาดแปลงสำหรับโดรน: ถาดพลาสติกขอบเตี้ย (~60x80 ซม.) วางต้นกล้าจำลองสีเขียวสดบนพื้นสีน้ำตาล/ดำตัดกันชัด
   (ช่วยให้กล้องโดรนแยกสีเขียว ExG ได้แม่นยำ) และกันน้ำกระเด็นโดนอุปกรณ์อื่น
2. ถาดดิน 3 จุด: ใส่ดินจริง 3 จุดลงกล่องเล็ก 3 ใบ ติดป้าย จุด A, B, C วางคู่กันสำหรับจิ้มหัววัดสดหน้างาน

[4] ข้อมูลที่คนที่ 4 ต้องส่งให้คนที่ 1
( ) ตารางเกณฑ์ N, P2O5, K2O และช่วง pH จริงของพืช 3 ชนิดจากคู่มือกรมวิชาการเกษตร 2565
( ) ผลตรวจค่าดินจริงของจุด A, B, C (ชนิดดิน, pH, ระดับ N, P, K)
( ) ผลบันทึกการหมักปุ๋ย (จำนวนวัน, อุณหภูมิ, สี/กลิ่น, และค่า TDS/EC หลังกรอง) สำหรับใส่เล่มรายงาน
